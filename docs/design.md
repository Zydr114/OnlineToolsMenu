# Talium 工具箱

## 当前设计：黑白几何（2026-10-16）

用户反馈明确要求去除引导性和装饰性文案，采用黑白配色、简洁的点线面动画，并强化科技感。本版替代首版的暖色、花形和纸张风格。

- 仅使用中性黑、白与灰阶；保留浅深两种主题及用户已有偏好。
- 首页只呈现工具箱名称、数量、工具名称、功能和入口。不放标语、成长提示或创作寄语。
- 方形标识、低圆角卡片、细分隔线和等宽数字。工具卡片整块可点击，箭头表达跳转。
- Canvas 2D 绘制点、线和离散面片构成的几何体，支持旋转、指针响应、圆/方结构变形。无渐变、发光光晕、花形或手绘元素。
- 波形和时间轴简化为纯图形，移除仿应用窗口、示例歌词和装饰标签。
- 搜索、主题、动效、关于、键盘导航等功能保留；动效使用图标与可访问名称表达，不弹出无关提示。
- 动画目标约 30fps；画布分辨率上限 2×，离屏和后台暂停。减少动效时只绘制静态结构，点击直接切换形态。
- 桌面尽量在一个视口呈现完整工具目录，手机单列；语义化 HTML、键盘焦点、足够的文字对比度。

## 内容与技术

目前仅收录 MakoLrc Studio，入口为 `https://tool.talium.site/MakoLrcStudio/`。准确介绍歌词编辑、逐字打轴、LRC/TTML/ASS 和本地处理，不添加未确认工具或产品声明。

使用静态前端，无服务端、账号或统计。素材与字体随构建提供，无第三方运行时请求。字体子集随文案更新。

生产构建后，在 Chromium、Firefox、WebKit 验证主题、搜索、键盘操作、工具 URL、动效偏好、画布渲染与暂停、整卡点击、移动布局及自动无障碍检查。截图和运行日志写入忽略跟踪的 `artifacts/`。

## 部署

SSH 别名 `tencent`，使用当前已授权的免密 sudo。站点为 `https://tool.talium.site/`；保留既有 `/MakoLrcStudio/`、重定向、缓存规则及其他域名。使用独立版本目录、配置备份、原子切换与探活失败自动恢复，提供上一部署回滚。
