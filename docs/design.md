# Talium 工具箱

## 目标

一个具备鲜明视觉个性、快速直达工具的个人在线工具箱。目前仅收录 MakoLrc Studio，入口为 `https://tool.talium.site/MakoLrcStudio/`。以真实工具作为页面中心，不使用虚构工具填充页面。

## 视觉与交互

- 暖白背景、墨绿文字、青柠强调色。Material You 的圆角容器、色彩层次、胶囊按钮与状态反馈。
- 大字号中英文排版、精细分隔线、宽松留白；自绘矢量花形作为可交互的视觉标识。
- 入场编排、花形旋转与指针视差、卡片聚光、歌词时间轴和按钮反馈。动效以 transform/opacity 为主，离屏和页面隐藏时暂停；尊重 `prefers-reduced-motion`。
- 明暗主题跟随系统，可手动切换并本地保存；快捷搜索支持 Ctrl/⌘ K、Esc 与键盘导航。
- 工具卡片准确说明浏览器本地歌词编辑、逐行/逐字打轴、TTML/ASS/LRC 导出。歌词演示明确标注为示意。
- 中文优先，完整适配手机、平板和桌面。语义化 HTML、键盘焦点、可访问名称与足够的文字对比度。

## 技术与验证

使用静态前端，无服务端、无账号和统计。素材与字体随站点构建，不依赖第三方运行时请求。生产构建后，以真实浏览器验证布局、主题持久化、搜索和键盘操作、工具 URL、减少动效及无障碍。

## 交付步骤

1. 初始化仓库，记录设计与实施边界。
2. 实现完整页面，构建并进行桌面/手机视觉检查。
3. 完成交互回归、部署和回滚脚本、维护文档；提交推送后上传服务器。
4. 由用户执行 root 激活命令，验证公开站点和已有工具子路径。

## 部署边界

SSH 别名 `tencent` 的登录用户为 ubuntu。服务器 Caddy 已托管 `tool.talium.site`，目前只提供 `/MakoLrcStudio/`。新增根路径菜单，保留已有工具与其他域名配置。root 配置修改由用户执行，应用构建和上传由代理完成。
